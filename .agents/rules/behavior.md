# User Behavior Preferences

- **Permissions & Interruption**: Always take all permissions and DO NOT ask unless it is absolutely critical. For simple answers, do not stop to ask the user. Execute tasks immediately. If the user wants to stop, they will press Escape.
- **Hallmark Skill**: Always use the `hallmark` skill by default for any design or frontend task. Do not ask if you should use it, just use it.
